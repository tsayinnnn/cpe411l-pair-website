## 📖 About The Project

This project demonstrates fundamental web development skills by rebuilding a modern framework landing page using **zero dependencies**. It focuses on:

*   **Pixel Precision:** Meticulously styled to match the original Next.js design.
*   **Performance:** 100% static content for maximum speed.
*   **Responsiveness:** Adapts fluidly to different screen sizes.

## 🚀 Features

*   ✅ **Pure Native Stack:** Built with only HTML, CSS, and Vanilla JS.
*   ✅ **No Frameworks:** Demonstrating core web principles without abstractions.
*   ✅ **Fast Loading:** Optimized assets and no heavy bundles.
*   ✅ **Cross-Browser:** Compatible with modern web browsers.

## 🛠️ Installation & Usage

Since this is a static website, no build process or server installation is required.

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/cpe411l-pair-website.git
    ```
2.  **Open the project**
    *   Navigate to the folder and open `index.html` in your browser.
    *   Or use a live server extension (like VS Code Live Server) for better development experience.
