# Next.js Landing Page Clone

A pixel-perfect recreation of the Next.js landing page, constructed entirely with native web technologies. This project demonstrates fundamental web development skills by rebuilding a modern framework landing page using only HTML, CSS, and JavaScript.

## Project Information
*   **Course:** CPE411L - Web Systems and Technologies Laboratory
*   **Authors:** Charlene Fernandez & Ryan Gapac
*   **Year:** 2026

## Features
*   **Zero Frameworks:** Built with pure HTML5, CSS3, and Vanilla JavaScript.
*   **Pixel Precision:** Meticulously styled to match the original design language of Next.js.
*   **Performance:** Optimized for speed with 100% static content and zero dependencies.
*   **Responsive:** Adapts to different screen sizes.

## How to Run
Since this is a static website, no build process or server installation is required.
1.  Clone or download the repository.
2.  Open `index.html` in your preferred web browser.

## File Structure
*   `index.html`: The main homepage replicating the Next.js landing page.
*   `about.html`: Details about the project and its design philosophy.
*   `docs.html`: Documentation page.
*   `showcase.html`: Showcase page.
*   `style.css`: Global styles and layout definitions.
*   `script.js`: Interactivity and logic.
