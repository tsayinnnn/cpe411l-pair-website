Introduction to Next.js

Next.js is a React framework that gives you the best developer experience with all the features you need for production: hybrid static & server rendering, TypeScript support, smart bundling, route pre-fetching, and more.

This documentation provides a comprehensive guide to building applications with Next.js. Whether you're a beginner or an experienced developer, you'll find resources here to help you get started and master the framework.

Installation

To get started with a new Next.js project, open your terminal and run the following command: 

npx create-next-app@latest my-next-app

This will create a new directory named `my-next-app` with all the necessary files to start developing. Navigate into the directory and start the development server: 

cd my-next-app
npm run dev

Your Next.js application will now be running on `http://localhost:3000`.

Basic Concepts

Pages and Routing

In Next.js, a "page" is a React Component exported from a `.js`, `.jsx`, `.ts`, or `.tsx` file in the `pages` directory. Each page is associated with a route based on its file name. For example, `pages/about.js` automatically maps to `/about`.

Components

Next.js uses React components to build user interfaces. Components are reusable, self-contained pieces of code that define a part of your UI. 

// components/MyButton.js
import React from 'react';

function MyButton({ children }) {
  return (
    <button style={{ padding: '10px 20px', backgroundColor: 'blue', color: 'white', border: 'none', borderRadius: '5px' }}>
      {children}
    </button>
  );
}

export default MyButton;

You can then import and use this component in your pages or other components.

Styling Your Application

Next.js supports various styling methods, including CSS Modules, Styled Components, Emotion, and Tailwind CSS.

CSS Modules

CSS Modules are a great way to scope your CSS locally to components. Simply name your CSS files with the `.module.css` extension, and Next.js will handle the rest. 

/* styles/Button.module.css */
.button {
  background-color: green;
  color: white;
  padding: 10px 15px;
  border-radius: 4px;
}
// components/AnotherButton.js
import styles from '../styles/Button.module.css';

function AnotherButton() {
  return <button className={styles.button}>Click Me</button>;
}

export default AnotherButton;
